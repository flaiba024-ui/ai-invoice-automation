# 🤖 AI Invoice Automation

An AI-powered invoice processing workflow built with **n8n** that automates invoice data extraction, organization, and email communication.

## 🔄 How It Works

**Invoice Submission → PDF Extraction → AI Information Extraction → Google Sheets → LLM Processing → Gmail**

The workflow receives an invoice through a form, extracts relevant information using AI, stores the data in Google Sheets, and generates an automated email response.

## ✨ Key Benefits

* 📄 Automates invoice data extraction
* 🤖 Reduces manual data entry
* 📊 Keeps invoice records organized in Google Sheets
* ✉️ Automates invoice-related email communication
* ⚡ Saves time on repetitive administrative tasks
* 🎯 Reduces the risk of manual data-entry errors

## 🛠️ Tech Stack

**n8n · OpenAI · Google Sheets · Gmail · PDF Extraction**
